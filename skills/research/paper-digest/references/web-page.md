# 网页来源的处理

输入是网页链接（技术博客、项目页、期刊 HTML 版）时，页面就是原文。本文说明怎么读它、怎么存档、怎么取图和表。

## 读全文

1. 抓取页面 HTML 后转成纯文本再读：去掉 `<script>`、`<style>`，标题标签换成 Markdown `#`，`<img>` 换成 `[IMG:src]` 占位，表格行保留换行。这样一次能看到全文结构，图片位置也在文本里。
2. 折叠区块（`<details>`、「Setup」「Show more」之类）里常放实验设置和训练细节，转文本时会一并展开，读的时候别跳过。
3. 页面内嵌的表格（`<table>`）直接从文本里读数字。用 JavaScript 渲染出来的图表（柱状图、热力图）文本里只剩标签，要截图看。
4. 页面常不编号实验章节，引用位置时用页面自己的标记：「Experiment 8 表」「Figure 2」「Setup 区块」。
5. 作者、机构、发表日期从页面头部取；没有同行评审的写「博客文章，非同行评审」。

## 存档 PDF

用无头浏览器把页面打印成 PDF 作为 `<方法简称>.pdf`，打印前等页面脚本跑完（给 10 到 20 秒的虚拟时间预算），否则动态渲染的图表会是空白。打印版只做存档，截图不从它裁，从渲染后的页面直接取。

## 取图

按优先级：

1. **原图文件**：`<img src>` 指向 PNG、SVG、GIF 的，拼成绝对 URL 直接下载。SVG 存为 SVG，笔记里按图片引用。
2. **按元素截图**：图是 HTML 和 CSS 画出来的（网格、柱条、JavaScript 图表）时，用无头浏览器加载页面，等脚本跑完，按 `<figure>` 或图容器元素的边界框截图。设备像素比取 2，截完按目标宽度缩放。页面首屏有轮播或动画时多等几秒再截，否则截到中间帧。
3. **GIF 动图**：原文件下载，不转帧。判断标准是它展示方法效果（演示、前后对比、训练过程），装饰性的不收。

图只截图本身，不含页面图注；图注在笔记里另写中文。

## 取表

页面内嵌表格按 `<table>` 所在的 `<figure>` 或容器元素截图，含表题和表注。截完检查两侧留白，多余的裁掉，再按表的物理宽度缩放：单栏表约 1000 px、小表约 700 px。

## 代码与演示链接

页面里出现的 GitHub、Hugging Face、在线 demo 链接都列进「代码 / 演示」行，用一两个字说明每个链接是什么（日志、模型、演示）。
