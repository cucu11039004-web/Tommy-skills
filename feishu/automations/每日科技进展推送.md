# 每日科技进展推送

调度：`50 8 * * *`，每天 08:50（Asia/Shanghai），云电脑运行。

## 提示词原文

```
本次请求是由「每日科技进展推送」定时任务到时触发的。请生成今日科技进展日报并推送给用户，具体要求如下：

【推送形式与规模】
1. 时间窗口：覆盖前一天 0 点至本次推送时的新内容
2. 精选 8-12 条/天，宁缺毋滥，不凑数
3. 交付形式：生成一份结构化飞书文档（按板块分类、包含全部可点击链接、可沉淀归档），并在对话消息中附核心摘要 + 飞书文档链接
4. 每条内容必须包含：一句话摘要、为什么值得关注、论文/项目主页/GitHub/新闻原文链接、开源状态标注（开源且活跃 / 有 Demo 但闭源 / 纯论文）

【内容板块与来源】
1. ArXiv 论文：
   - 机器人领域：侧重仿生机器人（足式、软体、人形、飞行/游泳仿生等），但不限于仿生机器人，同时覆盖 SLAM、操作、具身智能等相关方向
   - AI/大模型领域：重点抓 Agent 大模型方向的语音对话与人机交互——全双工语音、实时对话模型、低延迟流式交互、多模态 Agent 等前沿方向，只要足够前沿（哪怕闭源只有 Demo）也要收录
2. GitHub 开源项目：机器人 + AI 领域新上榜/增长迅速的开源项目
3. 顶会顶刊：NeurIPS / ICML / ICLR / ICRA / IROS / CoRL / RSS / ACL 等，以最新收录、获奖论文、社区热议为线索
4. 新闻媒体：科技媒体、微信公众号、X(Twitter)、Facebook、Meta 等平台上的机器人与大模型进展报道（微信公众号和海外社交平台无法直接抓取原文，通过新闻检索间接覆盖，确保主流重大进展不遗漏）

【论文/项目筛选优先级（严格按此排序）】
1. 有项目主页（Demo 主页）+ GitHub 真实开源代码：必须验证代码真实性与活跃度（Star 数、Issues 活跃度、最近 commit 时间），排除只有空 README 的壳项目
2. 有好的 Demo 效果、有项目主页但闭源：闭源也要收录，用户需要了解最新进展
3. 纯论文发表：优先关注有开源代码的论文

【其他】
- 每天推送（含周六周日），周末内容少则精简但不断更
- 用户会基于推送内容（论文、开源项目、新闻）自行深挖，无需替用户做扩展分析，把推送本身做精即可
- 用户可随时通过对话调整关注领域（增加/移除/临时加权），以任务配置中的最新需求为准
```
